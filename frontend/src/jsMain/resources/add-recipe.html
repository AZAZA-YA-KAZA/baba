Добавить рецепт

Теперь рецепт сохраняется нормально: отдельно карточка рецепта, отдельно ингредиенты, отдельно шаги приготовления.

Основная информация

Ингредиенты

Например: Мука — 300 — г. Количество должно быть числом, потому что в backend поле `count: Int`.

Шаги приготовления

Каждый шаг сохранится отдельной записью через `/api/kulinare/{idRecipe}/step`.
